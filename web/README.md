# LaundryFlow Super Admin Web Application

Production-ready React web application for the LaundryFlow Super Admin platform.

## Tech Stack
- React 18
- Vite
- JavaScript (ES Modules)
- Tailwind CSS
- React Router DOM
- Axios
- Zustand
- TanStack React Query
- Recharts
- Lucide React
- Framer Motion
- React Hot Toast

## Available Scripts

In the `web/` directory, you can run:

- `npm run dev` - Starts the Vite development server at http://localhost:3000
- `npm run build` - Builds the application for production to `dist/`
- `npm run preview` - Locally previews the production build
- `npm run lint` - Runs ESLint to check for code issues

## Environment Variables

- `VITE_API_URL` - Base backend API URL (default: `http://localhost:8080`)
